# Web-Traffic-Analysis
Website traffic and user engagement analytics dashboard built in Power BI.

## Project Overview

This Power BI dashboard analyzes website traffic, user engagement, traffic sources, bounce rates, and conversion performance.

The dashboard provides insights into visitor behavior and marketing channel effectiveness to support data-driven digital marketing decisions.

## Tools Used

- Power BI
- DAX
- Power Query

## Business Objectives

- Monitor website traffic performance
- Analyze visitor engagement
- Evaluate traffic source effectiveness
- Track conversion rates
- Identify opportunities to improve user retention

## Dashboard Features

### Website KPIs
- Total Sessions
- Average Page Views
- Average Session Duration
- Bounce Rate
- Conversion Rate

### Traffic Source Analysis
- Organic Traffic
- Paid Traffic
- Referral Traffic
- Social Traffic
- Direct Traffic

### Engagement Analysis
- High Quality Session Percentage
- Engagement Levels by Source
- Bounce Rate by Traffic Source

## Key Insights

- Organic traffic generated the largest share of website visits.
- High-quality sessions represented 67% of total traffic.
- Conversion rates remained strong across the reporting period.
- Bounce rates varied across traffic sources, highlighting opportunities for optimization.
- Traffic source analysis identified the most valuable acquisition channels.
